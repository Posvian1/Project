# Исследование оттока сотрудников и удовлетворенности персонала

**Автор:** Posvian1

**Цель проекта:** Разработать комплексное решение для HR-аналитики, направленное на оптимизацию управления персоналом. Проект состоит из двух ключевых задач: прогнозирование удовлетворенности сотрудников и анализ факторов, влияющих на увольнение.

## 📊 Задача 1: Прогнозирование удовлетворенности сотрудников

**Цель:** Построить модель машинного обучения для предсказания уровня удовлетворенности работой (`job_satisfaction_rate`) на основе имеющихся данных.

**Проделанная работа:**
1.  **Исследовательский анализ данных (EDA):**
    *   Проведен анализ распределений признаков и целевой переменной.
    *   Построены корреляционные матрицы (диаграммы рассеяния и тепловые карты) для выявления взаимосвязей между признаками.
2.  **Подготовка данных:**
    *   Разделены признаки на категориальные и количественные.
    *   Применены различные стратегии кодирования: `OneHotEncoder` для номинативных признаков (`dept`, `last_year_promo`, `last_year_violations`) и `OrdinalEncoder` для порядковых (`level`, `workload`).
    *   Масштабирование количественных признаков выполнено с помощью `StandardScaler` и `MinMaxScaler`.
    *   Пропуски в данных обработаны с использованием `SimpleImputer`.
3.  **Построение и обучение модели:**
    *   Создан пайплайн для предобработки данных и обучения моделей.
    *   Выполнен поиск гиперпараметров с помощью `GridSearchCV` для следующих моделей:
        *   `LinearRegression`
        *   `DecisionTreeRegressor`
    *   В качестве метрики качества использована **sMAPE (Symmetric Mean Absolute Percentage Error)**.

**Результат:** Лучшей моделью оказалась **`DecisionTreeRegressor`** со следующими параметрами: `max_depth=13`, `max_features=11`. Метрика sMAPE на тренировочной и тестовой выборках составила **~14.6%**.

## 🏢 Задача 2: Анализ оттока сотрудников

**Цель:** Изучить факторы, влияющие на увольнение сотрудников (`quit`), и построить модель для прогнозирования этого события.

**Проделанная работа:**
1.  **Исследовательский анализ данных (EDA):**
    *   Проанализирована доля уволившихся сотрудников в разрезе различных признаков:
        *   **Департамент (`dept`)**: Наибольший процент увольнений наблюдается в отделах "hr" и "sales".
        *   **Уровень загрузки (`workload`)**: Уволившиеся сотрудники чаще имели среднюю ("medium") и низкую ("low") загрузку.
        *   **Зарплата (`salary`)**: У уволившихся сотрудников наблюдается более низкая средняя зарплата по сравнению с теми, кто остался.
2.  **Генерация нового признака:**
    *   Для улучшения качества модели был создан новый признак **`job_satisfaction_rate`** — прогнозное значение удовлетворенности, полученное из модели, обученной в Задаче 1.
3.  **Выводы:** Анализ показал, что ключевыми факторами оттока являются принадлежность к определенным департаментам, уровень загрузки и размер заработной платы.

## 🛠️ Используемые технологии и библиотеки

*   **Язык программирования:** Python
*   **Библиотеки:**
    *   `pandas`, `numpy` — для обработки и анализа данных.
    *   `matplotlib`, `seaborn` — для визуализации данных.
    *   `scikit-learn` — для построения моделей машинного обучения (`LinearRegression`, `DecisionTreeRegressor`, `RandomForestClassifier`), предобработки данных (`OneHotEncoder`, `OrdinalEncoder`, `StandardScaler`, `MinMaxScaler`, `SimpleImputer`) и поиска гиперпараметров (`GridSearchCV`).

## 📈 Ключевые выводы

*   Модель на основе **DecisionTreeRegressor** показала высокую точность (sMAPE ~14.6%) в прогнозировании удовлетворенности сотрудников.
*   На отток сотрудников наиболее сильно влияют **департамент, загруженность и уровень зарплаты**.
*   Использование прогнозной удовлетворенности (`job_satisfaction_rate`) как дополнительного признака может повысить качество модели прогнозирования оттока.
