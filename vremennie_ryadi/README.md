# Прогноз заказов такси

## Описание задачи
Компания такси хочет прогнозировать количество заказов на следующий час, чтобы оптимизировать количество машин на линии и сократить время подачи.

## Данные
- Временной ряд с почасовой агрегацией заказов
- Период: несколько месяцев
- Целевая переменная: количество заказов в час

## Используемые инструменты
- **Python:** pandas, numpy, matplotlib, seaborn, scikit-learn
- **Модели:** LinearRegression, RandomForest, LightGBM
- **Метрика:** RMSE

## Методология
1. Проведён анализ временного ряда: выявлены суточные и недельные сезонности.
2. Созданы временные признаки (час, день недели, месяц, праздники).
3. Обучены модели с использованием кросс-валидации.
4. Выбрана лучшая модель по RMSE.

## Результаты
- **Лучшая модель:** RandomForest
- **RMSE на тесте:** 45.5 (целевой показатель — 48)
- Модель готова к использованию в системе планирования ресурсов

## Как запустить
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install pandas numpy matplotlib seaborn scikit-learn lightgbm`
3. Запустите Jupyter Notebook.

## Выводы
Модель успешно справляется с прогнозированием спроса и может быть интегрирована в систему управления парком такси.
