# Прогнозирование стоимости подержанных автомобилей

## Описание задачи
Компания по продаже автомобилей хочет автоматизировать оценку рыночной стоимости подержанных машин на основе их характеристик. Цель — разработать модель машинного обучения, которая по историческим данным предсказывает цену автомобиля, что позволит ускорить обработку объявлений и повысить точность ценообразования.

## Данные
- Источник: датасет `autos.csv` (более 300 000 записей).
- Признаки: тип кузова, год регистрации, тип коробки передач, мощность, модель, пробег, тип топлива, марка, статус ремонта.
- Целевая переменная: `Price` (цена в евро).

## Используемые инструменты
- **Python:** pandas, numpy, matplotlib, seaborn, scikit-learn
- **Модели:** LinearRegression, RandomForestRegressor, CatBoostRegressor, LightGBM
- **Метрики:** MAE, RMSE
- **Предобработка:** OrdinalEncoder, StandardScaler, удаление выбросов и пропусков

## Методология
1. **Анализ и очистка данных:** удалены дубликаты, отфильтрованы аномалии (цена < 10 €, год регистрации вне 1970–2017, мощность вне 40–600 л.с.), пропуски в категориальных признаках заполнены значением `'N/A'`.
2. **Кодирование и масштабирование:** категориальные признаки преобразованы с помощью `OrdinalEncoder`, все признаки стандартизированы `StandardScaler`.
3. **Разделение выборки:** 75 % — обучающая, 25 % — тестовая.
4. **Обучение моделей:** обучены 4 модели с кросс-валидацией (5 фолдов), замерялось время обучения и качество предсказаний.
5. **Выбор лучшей модели** по минимальному RMSE на тестовой выборке.

## Результаты
| Модель               | MAE   | RMSE  | Время обучения (с) |
|----------------------|-------|-------|---------------------|
| LinearRegression     | 1977  | 3056  | 0.01                |
| RandomForestRegressor| 1302  | 1962  | 3.17                |
| CatBoostRegressor    | 1217  | 1869  | 3.99                |
| LightGBM             | 1212  | 1847  | 2.13                |

**Лучшая модель:** LightGBM (RMSE = 1847, MAE = 1212).  
Наиболее значимые признаки: год регистрации и мощность двигателя. Модель готова к интеграции.
