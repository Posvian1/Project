# Увеличение покупательской активности постоянных клиентов сервиса «В один клик»

Проект направлен на прогнозирование снижения покупательской активности клиентов на основе их поведения за предыдущие месяцы. Основная цель — построить модель машинного обучения, которая позволит выявлять клиентов с высоким риском ухода и своевременно применять меры по их удержанию.

---

## 📊 Данные

Исходные данные представлены в четырёх таблицах:

- `market_file.csv` — основная информация о клиентах и их взаимодействии с сервисом.
- `market_money.csv` — выручка за три месяца (предыдущий, текущий, препредыдущий).
- `market_time.csv` — время (в минутах), проведённое на сайте за два месяца.
- `money.csv` — общая прибыль от клиента.

**Целевая переменная:** `покупательская активность` — бинарный признак (`снизилась` или `прежний уровень`).

---

## 🧹 Предобработка данных

- Приведение названий столбцов к единому формату (нижний регистр).
- Исправление опечаток: `стандартт` → `стандарт`, `предыдцщий` → `предыдущий`.
- Удаление пользователей с нулевой выручкой за три месяца (неактивные клиенты).
- Удаление признаков-утечек: `выручка текущий месяц`, `минут текущий месяц` (эти данные недоступны на момент прогноза).
- Устранение мультиколлинеарности и удаление слабо коррелирующих признаков.
- Создание новых категориальных признаков на основе непрерывных (бинаризация по порогам).

---

## 🔍 Исследовательский анализ данных (EDA)

- Построены распределения числовых и категориальных признаков.
- Выявлен дисбаланс классов (клиентов со снижением активности меньше).
- Построены корреляционные матрицы (Phik и линейная корреляция).
- Обнаружена группа клиентов, которые долго просматривают сайт, добавляют товары в корзину, но не оформляют заказ — это может быть индикатором будущего снижения активности.
- Наиболее значимые признаки по корреляции с целевой переменной:
  - `маркет актив 6 мес`
  - `акционные покупки`
  - `ошибка сервиса`
  - `страниц за визит`
  - `выручка предыдущий месяц`

## 🧪 Моделирование

Использован пайплайн с автоматическим подбором гиперпараметров через `OptunaSearchCV`.

**Этапы обработки в пайплайне:**
- One-hot-кодирование категориальных признаков.
- Порядковое кодирование бинарных категорий.
- Масштабирование числовых признаков (`StandardScaler` / `MinMaxScaler` / без масштабирования).
- Генерация полиномиальных признаков 2-й степени.
- Балансировка классов с помощью `SMOTENC` (учитывает категориальные признаки).

**Модели (сравнивались):**
- KNeighborsClassifier
- DecisionTreeClassifier
- LogisticRegression (с ElasticNet)
- SVC

**Метрика оптимизации:** ROC-AUC (5‑кратная кросс-валидация).

---

## 📈 Результаты

Лучший результат показала **LogisticRegression**:

| Модель | ROC‑AUC (CV) |
|--------|--------------|
| **LogisticRegression** | **~0.8965** |
| KNeighborsClassifier | ~0.8866 |
| DecisionTreeClassifier | ~0.8592 |
| SVC | — (тестировалась) |

**Оптимальные гиперпараметры лучшей модели:**
- `C = 5`
- `l1_ratio = 0.8`
- `over__k_neighbors = 4`
- `preprocessor__num__scaler = StandardScaler()`

---

## 🔍 Анализ важности признаков

С помощью **Permutation Importance** определены ключевые факторы, влияющие на снижение активности:

1. **Маркетинговая активность за 6 месяцев** — чем ниже, тем выше риск.
2. **Акционные покупки** — клиенты, редко участвующие в акциях, чаще уходят.
3. **Ошибки сервиса** — технические проблемы снижают лояльность.
4. **Количество страниц за визит** — низкая глубина просмотра сигнализирует о слабом интересе.
