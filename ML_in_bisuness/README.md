## Описание проекта

**Цель проекта** — разработать модель машинного обучения, которая поможет выбрать наиболее прибыльный регион для разработки новых нефтяных скважин.  
Задача решается на основе геологоразведочных данных трёх регионов. Для каждого региона строится модель линейной регрессии, предсказывающая объём запасов (тыс. баррелей) по трём признакам (`f0`, `f1`, `f2`).  
На основе предсказаний рассчитывается ожидаемая прибыль и риск убытков, после чего выбирается оптимальный регион для бурения.

---

## Данные

В проекте используются три датасета:
- `geo_data_0.csv`
- `geo_data_1.csv`
- `geo_data_2.csv`

Каждый файл содержит 100 000 записей о скважинах со следующими признаками:
- `id` – уникальный идентификатор скважины,
- `f0`, `f1`, `f2` – три признака геологоразведки (закодированные показатели),
- `product` – целевая переменная (объём запасов, тыс. баррелей).

Данные уже предобработаны: удалены пропуски и дубликаты, обработаны выбросы.  
Для улучшения качества моделей были добавлены новые признаки:
- `f3 = f0 * f1`
- `f4 = f0 / f1`
- `f5 = f0²`
- `f6 = f1²`
- `f7 = f2²`
- `f8 = f0 + f1`

## Этапы работы

1. **Загрузка и первичный анализ данных**  
   - Загрузка трёх датасетов.
   - Проверка на пропуски и дубликаты.
   - Обработка дублирующихся `id` (добавление суффиксов `_1`, `_2`).

2. **Визуализация и разведочный анализ (EDA)**  
   - Построение ящиков с усами для выявления выбросов.
   - Удаление выбросов (менее 1% от всех данных).
   - Матрицы диаграмм рассеяния и тепловые карты корреляций для каждого региона.

3. **Генерация новых признаков**  
   - Создание 6 новых признаков на основе существующих.
   - Повторная визуализация для оценки влияния новых признаков.

4. **Построение моделей**  
   - Для каждого региона обучается модель линейной регрессии.
   - Данные разбиваются на обучающую и валидационную выборки (75% / 25%).

5. **Оценка качества моделей**  
   - Расчёт средней абсолютной ошибки (MAE) и среднеквадратичной ошибки (RMSE) на валидационной выборке.

6. **Расчёт прибыли и рисков**  
   - Бюджет на разработку: 10 млрд руб.
   - Доход с одной скважины: 450 тыс. руб. за тыс. баррелей.
   - Выбираются 200 лучших скважин (по предсказаниям модели) для каждого региона.
   - Оценивается средняя прибыль и 95-й процентиль риска убытков (с использованием бутстрапа).

7. **Выбор лучшего региона**  
   - Сравнение трёх регионов по средней прибыли и уровню риска.

|-------------|-----------------------------|--------------------------------|
| geo_data_0  | 4.22                         | 5.1%                           |

**Лучший регион** – **geo_data_2**:  
- Средняя прибыль: **4.36 млрд руб.**  
- Риск убытков: **4.2%** (ниже 5% порога).

Модель показала высокую точность предсказаний (RMSE ~ 30–40 тыс. баррелей).  
Для региона geo_data_1 наблюдалась сильная корреляция между `f2` и `product`, что могло указывать на особенности данных.

## Выводы

- Разработанная модель позволяет с высокой точностью прогнозировать объёмы запасов.
- Регион **geo_data_2** является наиболее перспективным для бурения при заданных экономических условиях.
- Применённый подход с бутстрапом позволил количественно оценить риски и принять обоснованное решение.
- Методология может быть масштабирована на другие регионы или использована для переоценки перспективности уже разрабатываемых месторождений.
