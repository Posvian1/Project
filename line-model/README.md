# 🐄 Молочное хозяйство «Вольный луг» — модель машинного обучения

Этот проект посвящён анализу данных молочного хозяйства и построению моделей для прогнозирования **удоя коров** и **вкуса молока**.  
Решение включает полный цикл: от загрузки и очистки данных до обучения и оценки моделей машинного обучения.

---

## 📁 Структура проекта
line-model/
├── line-model.ipynb              # основной Jupyter Notebook с анализом и моделями
├── README.md                     # этот файл
└── datasets/                     # директория с данными (предполагается локально)
    ├── ferma_main.csv            # основные данные о коровах
    ├── ferma_dad.csv             # данные об отцах быков
    └── cow_buy.csv               # данные о закупленных коровах

---

## 🎯 Цель проекта

- **Предсказать удой коров** (регрессия) на основе их характеристик, рациона и происхождения.
- **Предсказать вкус молока** («вкусно» / «не вкусно») с помощью классификации.
- Провести разведочный анализ данных (EDA) и корреляционный анализ.

---

## 📊 Данные

Используются три набора данных:

1. **`ferma_main.csv`** — основная таблица с информацией о каждой корове:
   - Удой (кг)
   - Энергетическая кормовая единица (ЭКЕ)
   - Сырой протеин (г)
   - Сахаро-протеиновое соотношение (СПО)
   - Порода, тип пастбища, порода отца
   - Жирность и белок молока
   - Вкус молока (бинарный признак)
   - Возраст (категориальный)

2. **`ferma_dad.csv`** — справочник: `id` отца и его кличка.

3. **`cow_buy.csv`** — данные о коровах, приобретённых для хозяйства.

---

## 🧹 Предобработка данных

- Приведены к единому регистру имена столбцов.
- Заменены десятичные запятые на точки в числовых признаках.
- Удалены явные и неявные дубликаты.
- Исправлены синонимы в категориальных признаках:
  - `Вис Бик Айдиал` → `Айдиал`
  - `РефлешнСоверинг` → `Соверинг`
  - `Айдиалл` → `Айдиал`
  - `Равнинные` → `равнинное`
- Типы данных приведены к корректным (`float` для вещественных, `object` для категорий).

## 📈 Разведочный анализ данных (EDA)

### Количественные признаки
- `удой(кг)` — выявлен и удалён значительный выброс (> 8000 кг). Распределение асимметричное.
- `ЭКЕ` — выбросов нет, распределение скошено.
- `сырой протеин(г)` — выбросов нет, распределение скошено.
- `СПО` — выбросов нет, распределение скошено.
- `жирность(%)` — множество выбросов ниже первой квартили.
- `белок(%)` — несколько выбросов, распределение близко к нормальному.

### Категориальные признаки
- Все категориальные признаки (порода, тип пастбища, порода папы, вкус, возраст) не вызывают подозрений.
- В датафрейме `cow_buy` признаки также корректны.

## 📊 Корреляционный анализ

Построена тепловая карта корреляций для числовых признаков.  
Наиболее сильная связь наблюдается между:
- `удой(кг)` и `ЭКЕ`
- `удой(кг)` и `сырой протеин(г)`
- `жирность(%)` и `белок(%)`

---

## 🤖 Моделирование

### 1. Линейная регрессия (прогноз удоя)

- Используются признаки: `ЭКЕ`, `сырой протеин(г)`, `жирность(%)`, `белок(%)`, `порода`, `тип пастбища`, `порода папы`, `возраст`.
- Категориальные признаки закодированы с помощью `OneHotEncoder`.
- Применены `StandardScaler` для нормализации.
- Модель: `LinearRegression` + `Ridge` (L2-регуляризация) для борьбы с переобучением.

**Результаты (Ridge):**
- **R²** (train): ~0.75
- **R²** (test): ~0.72
- **MAE** (test): ~180 кг
- **RMSE** (test): ~240 кг

✅ Модель показывает хорошую обобщающую способность. Наиболее значимые признаки: `ЭКЕ`, `сырой протеин(г)` и `порода`.

---

### 2. Логистическая регрессия (прогноз вкуса молока)

- Целевая переменная: `вкус молока` (бинарная: «вкусно» / «не вкусно»).
- Используются те же признаки, что и в регрессионной задаче.
- Модель: `LogisticRegression` с L2-регуляризацией.

**Результаты:**
- **Accuracy**: ~0.85
- **Precision**: ~0.84
- **Recall**: ~0.86
- **F1-score**: ~0.85

📌 Основные факторы, влияющие на вкус: `жирность(%)` и `белок(%)`.  
Модель демонстрирует высокую точность и сбалансированность.
