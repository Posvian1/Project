## Описание проекта

**Цель проекта** — разработать инструмент для автоматического выявления токсичных комментариев на платформе «Викишоп». Задача решается как бинарная классификация текстовых комментариев на основе их содержания. На основе обработанных текстовых данных строится модель машинного обучения, которая определяет, является ли комментарий токсичным.

**Ключевые результаты:**
- Лучшая модель: **LogisticRegression**
- Метрика **F1 > 0.75** достигнута на тестовой выборке
- Проведена полная обработка текстовых данных с созданием множества признаков

---

## Данные

В проекте используется датасет `toxic_comments.csv`, содержащий 159 292 записей комментариев со следующими признаками:

- `Unnamed: 0` – индекс записи
- `text` – текст комментария
- `toxic` – целевая переменная (1 — токсичный, 0 — нетоксичный)

**Распределение классов:**
- Нетоксичные комментарии: 143 106
- Токсичные комментарии: 16 186

Классы несбалансированы (соотношение ~8.84:1), что потребовало применения методов балансировки.

## Этапы работы

1. **Загрузка и первичный анализ данных**
   - Изучение структуры данных, проверка пропусков
   - Анализ распределения классов

2. **Предобработка текста**
   - Приведение к нижнему регистру
   - Токенизация и POS-тегирование с использованием NLTK
   - Лемматизация слов с учётом части речи
   - Удаление всего, кроме букв латинского алфавита
   - Удаление стоп-слов

3. **Векторизация текста**
   - Использование **TfidfVectorizer** с параметрами:
     - `ngram_range=(1, 2)` — униграммы и биграммы
     - `min_df=5` — игнорирование редких слов
     - `max_df=0.7` — игнорирование слишком частых слов
   - Получено 76 037 признаков

4. **Разделение выборки**
   - Обучающая выборка: 50% (79 646 записей)
   - Валидационная выборка: 30% (47 787 записей)
   - Тестовая выборка: 20% (31 859 записей)
   - Стратификация по целевой переменной

5. **Балансировка классов**
   - Сравнение трёх подходов:
     - Без балансировки
     - Балансировка через веса классов (`class_weight='balanced'`)
     - Уменьшение выборки (downsampling) класса 0
   - Выбран оптимальный метод — балансировка через веса классов

6. **Обучение моделей**
   - **LogisticRegression** с подбором гиперпараметров (GridSearchCV)
   - **DecisionTreeClassifier** с подбором глубины дерева
   - **CatBoostClassifier** с 250 итерациями

7. **Оценка качества**
   - Метрика: **F1-score**
   - Дополнительно: ROC-AUC, Precision, Recall, Accuracy

## Используемые технологии

- **Python** — основной язык программирования
- **Pandas, NumPy** — обработка и анализ данных

## Результаты

### Сравнение методов балансировки

| Метод балансировки | F1 на CV | F1 на валидации | ROC-AUC |
|---|---|---|---|
| Без балансировки | 0.6556 | 0.7401 | 0.9686 |
| Балансировка по весам | **0.7537** | **0.7652** | **0.9690** |
| Уменьшение выборки | 0.8061 | 0.6852 | 0.9606 |

**Вывод:** балансировка по весам классов показала наилучший результат на валидационной выборке и была выбрана для финального обучения.

---

### Сравнение моделей (с балансировкой по весам)

| Модель | F1 на CV | F1 на валидации | Выполнение задачи (F1 > 0.75) |
|---|---|---|---|
| **LogisticRegression** | **0.7537** | **0.7652** | ✅ **Да** |
| DecisionTreeClassifier | 0.6310 | 0.6409 | ❌ Нет |
| CatBoostClassifier | 0.7161 | 0.7338 | ❌ Нет |

## Выводы

- Исходные данные обладают большим количеством признаков (76 037), что характерно для текстовых задач.
- Лучшей моделью стала **LogisticRegression** с балансировкой классов по весам.
- Модель успешно справляется с задачей классификации токсичных комментариев, достигая целевого значения F1 > 0.75.
- **CatBoostClassifier** потенциально может показать более высокие результаты при длительном обучении и дополнительной настройке гиперпараметров.
